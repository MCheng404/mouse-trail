# 滑鼠拖尾

為 [Windhawk](https://windhawk.net/) 高度客製化的滑鼠游標拖尾模組。基於原生 D3D11 + DirectComposition 硬體加速，包含 23 種顏色模式、10 種拖尾渲染風格、9 種粒子形狀、完整牛頓粒子物理系統（質量、引力、碰撞、電磁力、湍流、流體耦合）、向心力渦流軌道捕獲、音樂反應音頻物理、2.5D 深度效果、點擊特效和文字/Emoji 粒子。獨立 Tool Mod 行程執行——閒置零 CPU，啟用時全硬體加速。

## 渲染架構

- **原生 D3D11 管線：** 自訂 HLSL 頂點/像素著色器，粒子實例化渲染。核心拖尾、粒子、形狀渲染不依賴 D2D1。
- **DirectComposition 硬體覆蓋層：** 預乘 alpha DXGI 翻轉交換鏈，per-pixel alpha，與桌面合成器無撕裂合成。
- **2.5D 深度效果：** 每個粒子帶 z 深度 + 透視投影 + 簡單光照 + 深度縮放（近大遠小近亮遠暗）。
- **雙執行緒設計：** UI 執行緒跑視窗訊息泵，渲染執行緒獨佔 D3D11/DComp。滑鼠輸入永不被渲染阻塞。
- **HDR 自動偵測：** 自動識別 HDR 顯示器並使用 R16G16B16A16_FLOAT，SDR 自動回退 BGRA8。
- **裝置遺失恢復：** 主動 `GetDeviceRemovedReason()` 輪詢 + `WM_POWERBROADCAST` 喚醒處理。GPU TDR、驅動更新、顯示卡切換或睡眠喚醒時全自動重建 D3D/DComp 堆疊——無黑幀。
- **顯示變化處理：** 顯示器切換或解析度變化時自動調整覆蓋層。
- **加法混合發光：** 拖尾、粒子、漣波發光層使用 SrcAlpha+One 加法混合，光暈更通透。
- **快速移動插值：** 幀間隔 ≤10ms 時沿路徑插值補粒子，消除快速移動縫隙。

## 拖尾渲染風格（10種）

- **錐形飄帶：** 經典漸隱飄帶，帶發光、陰影和頭部高光
- **圓點鏈：** 沿路徑排列的圓點，密度和大小可調
- **函數曲線：** 自訂數學函數變形軌跡（正弦、阻尼、心跳、漩渦或自訂公式）
- **波浪曲線：** 動態正弦波變形
- **形狀拖尾：** 沿路徑生成 9 種可選形狀（愛心、五角星、六邊形、圓形、菱形、三角形、花朵、五邊形、六芒星或隨機），帶隨機速度、旋轉、重力，間隔/大小/數量/存活時間可調
- **雙線拖尾：** 兩條平行拖尾帶
- **虛線拖尾：** 常數寬度分段虛線
- **螺旋拖尾：** 沿路徑螺旋變形
- **閃電拖尾：** 細亮鋸齒主線 + 35% 機率隨機分支
- **羽毛拖尾：** 細主軸 + 兩側斜向羽枝，自然羽毛弧度

## 顏色模式（23種）

單色 / 流動漸層 / 彩虹流動 / 暖色調流動 / 冷色調流動 / 霓虹脈衝 / 速度變色 / 流動條紋 / 火焰 / 極光 / 游標取色 / 游標混色 / 金屬金 / 賽博朋克 / 粉彩 / 色相旋轉 / 雙色脈衝 / 星光閃爍 / 熱力圖 / 波紋干涉 / 色譜分裂 / 顆粒抖動 / 漸層扭曲

## 漸層系統

- **任意數量顏色：** 添加任意數量漸層顏色（最多 16 種）
- **OKLab 感知均勻插值：** 無灰暗中點，感知均勻的色彩過渡
- **256色 LUT：** 預計算查找表，零幀分配
- **流動漸層：** 漸層沿路尾隨時間流動

## 取色偏移（6種模式）

關閉 / 互補色(180°) / 類似色(30°) / 三角色(120°) / 分裂互補(150°) / 自訂角度

## 視覺特效

- **貝茲平滑：** Catmull-Rom 樣條插值，曲線如絲般順滑
- **運動模糊：** 歷史幀疊加，透明度遞減（1–5 強度）
- **增強發光：** 雙層光暈（外暈+內輝），獨立開關
- **頭部高光 + 拖尾陰影：** 高級質感深度提示
- **速度響應寬度：** 快速移動時拖尾變寬

## 粒子物理系統

模組內建完整牛頓粒子物理引擎，每個力都有獨立開關：

- **粒子質量：** 每個粒子有隨機質量（Box-Muller 常態分布）。影響慣性、大小、生命週期和加速度（a=F/m）
- **粒子萬有引力：** 牛頓萬有引力定律 F=G·m₁·m₂/r² + Plummer 軟化。支持雙星或 N 體系統（2–10 個主導天體）
- **向心力渦流：** 滑鼠做曲線運動時粒子被捕獲到軌道上。角動量守恆 + 開普勒速度梯度 + 軌道進動 + 3D 軌道傾角
- **彈性碰撞：** 動量 + 動能守恆，按質量反比位置修正
- **洛倫茲力：** 帶電粒子在磁場中做圓周運動（F=q·v×B）
- **庫侖力：** 同號電荷相斥，異號電荷相吸
- **布朗運動/湍流：** Perlin-like 空間連貫噪聲場，產生流動感湍流
- **粘性耦合：** 鄰近粒子互相拖拽速度，產生流體般的團簇行為
- **空氣阻力：** 低速線性阻力 + 高速二次阻力，質量慣性 + 大小空氣阻力
- **自旋物理：** 粒子自旋帶旋轉空氣阻尼
- **彈簧（布料）：** 鄰近粒子間胡克定律彈簧 + 沿連線阻尼
- **環境重力/環境風：** 方向恆定加速度 + 陣風/擺動湍流
- **游標吸引+排斥：** 游標周圍力場

## 音樂響應框架

WASAPI 迴環擷取 + Cooley-Tukey FFT + 三種節拍偵測 + 多頻段分析 + BPM 估計 + 音樂物理連動（低頻→引力、中頻→磁場、高頻→熱噪聲）。

## 安裝

1. 安裝 [Windhawk](https://windhawk.net/)
2. 下載 `mouse-trail.wh.cpp`
3. 在 Windhawk 中點擊「建立 mod」→ 貼上程式碼 → 儲存

## 函數軌跡變數

自訂公式中可使用：`t`（歸一化位置 0=頭 1=尾）、`d`（距頭部像素距離）、`time`（秒）。函數：sin cos exp sqrt abs。運算子：+ - * / ^。
