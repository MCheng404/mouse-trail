# マウストレイル

[Windhawk](https://windhawk.net/) 用の高カスタマイズ可能なマウスカーソルトレイル mod。ネイティブ D3D11 + DirectComposition ハードウェアアクセラレーション基盤、23 のカラーモード、10 種のトレイル描画スタイル、9 種のパーティクル形状、完全なニュートン粒子物理システム（質量、重力、衝突、電磁力、乱流、流体結合）、求心力渦による軌道捕捉、音楽連動物理、2.5D 深度エフェクト、クリックエフェクト、テキスト/絵文字パーティクル搭載。独立 Tool Mod プロセスとして動作——アイドル時 CPU 使用率ゼロ、アクティブ時フルハードウェアアクセラレーション。

## レンダリングアーキテクチャ

- **ネイティブ D3D11 パイプライン:** カスタム HLSL 頂点/ピクセルシェーダー、インスタンシング描画。コアトレイル・パーティクル・形状描画は D2D1 に依存しません。
- **DirectComposition ハードウェアオーバーレイ:** 事前乗算 alpha DXGI フリップスワップチェーン、per-pixel alpha、デスクトップ合成器とのティアフリー合成。
- **2.5D 深度エフェクト:** 各パーティクルが z 深度 + 透視投影 + 簡易ライティング + 深度スケーリング（近大遠小・近明遠暗）を持ちます。
- **デュアルスレッド設計:** UI スレッドがウィンドウメッセージポンプを担当、レンダースレッドが D3D11/DComp を独占。マウス入力が描画によってブロックされることはありません。
- **HDR 自動検出:** HDR ディスプレイを自動検出し R16G16B16A16_FLOAT を使用、SDR は BGRA8 にフォールバック。
- **デバイスロス復旧:** 能動的 `GetDeviceRemovedReason()` ポーリング + `WM_POWERBROADCAST` ウェイク処理。GPU TDR、ドライバ更新、GPU 切替、スリープ復帰時に D3D/DComp スタックを自動再構築——ブラックフレームなし。
- **表示変更処理:** モニター切替や解像度変更時にオーバーレイを自動リサイズ。
- **加算ブレンドグロー:** トレイル・パーティクル・波紋のグローレイヤーは SrcAlpha+One 加算ブレンドで透過的なハローを実現。
- **高速移動補間:** フレーム間隔 ≤10ms 時、カーソルパスに沿ってパーティクルを補間し、高速移動時の隙間を解消。

## トレイル描画スタイル（10種）

- **テーパーリボン:** クラシックなフェードリボン、グロー・シャドウ・ヘッドハイライト付き
- **ドットチェーン:** パスに沿ったビーズ、密度・サイズ調整可能
- **関数カーブ:** カスタム数式でトレイルを変形（サイン、減衰、ハートビート、スパイラル、または独自数式）
- **ウェーブカーブ:** アニメーション波形変形
- **シェイプトレイル:** パスに沿って 9 種の形状（ハート、スター、六角形、円、ダイヤ、三角形、花、五角形、六芒星、またはランダム）を生成。ランダム速度・回転・重力、間隔/サイズ/数/寿命調整可能
- **ダブルライン:** 2 本の平行トレイルリボン
- **ダッシュ:** 一定幅のセグメント破線
- **スパイラル:** パスに沿った螺旋変形
- **ライトニング:** 細い明るいギザギザライン + 35% 確率でランダム分岐
- **フェザー:** 細い中心軸 + 斜めの羽枝、自然な羽毛カーブ

## カラーモード（23種）

単色 / 流動グラデーション / レインボーフロー / ウォームフロー / クールフロー / ネオンパルス / 速度カラー / ストライプ / ファイア / オーロラ / カーソル抽出 / カーソルミックス / メタリックゴールド / サイバーパンク / パステル / 色相回転 / デュアルパルス / スパークル / ヒートマップ / 位相干渉 / スペクトルスプリット / グレインジッター / グラデーションワープ

## グラデーションシステム

- **無制限カラー:** 最大 16 色まで追加可能
- **OKLab 知覚的補間:** グレー中間点なし、知覚的に均一な色遷移
- **256色 LUT:** 事前計算ルックアップテーブル、ゼロフレームアロケーション
- **流動グラデーション:** グラデーションが時間とともにトレイルに沿ってアニメーション

## カーソルカラーシフト（6種）

オフ / 補色(180°) / 類色(30°) / 三角色(120°) / スプリットコンプリメント(150°) / カスタム角度

## ビジュアルエフェクト

- **ベジェ平滑化:** Catmull-Rom スプライン補間で滑らかな曲線
- **モーションブラー:** 履歴フレームオーバーレイ、透明度逓減（1–5 強度）
- **強化グロー:** 二重レイヤーハロー（外側グロー + 内側ブルーム）、独立トグル
- **ヘッドハイライト + トレイルシャドウ:** プレミアムな奥行き演出
- **速度反応幅:** 高速移動時にトレイルが太くなる

## パーティクル物理システム

完全なニュートン物理エンジン搭載、各力に独立トグル：

- **パーティクル質量:** Box-Muller 正規分布によるランダム質量。慣性・サイズ・寿命・加速度に影響（a=F/m）
- **パーティクル重力:** ニュートン万有引力 F=G·m₁·m₂/r² + Plummer 軟化。2 体（連星）または N 体システム（2–10 体）対応
- **求心力渦:** 曲線マウス運動でパーティクルを軌道に捕捉。角運動量保存 + ケプラー速度勾配 + 軌道歳差 + 3D 軌道傾斜
- **弾性衝突:** 運動量 + 運動エネルギー保存、質量反比例位置補正
- **ローレンツ力:** 荷電粒子が磁場内で円運動（F=q·v×B）。正電荷は反時計回り、負電荷は時計回り
- **クーロン力:** 同符号電荷は反発、異符号電荷は吸引
- **ブラウン運動/乱流:** Perlin 風空間一貫ノイズフィールド、流れるような乱流を生成
- **粘性結合:** 近接パーティクル同士が速度をドラッグ、流体的なクラスター挙動
- **空気抵抗:** 低速線形抵抗 + 高速二次抵抗、質量慣性 + サイズ空気抵抗
- **スピン物理:** 粒子スピンの回転空気減衰
- **スプリング（布）:** 近接粒子間フックの法則スプリング + 軸方向減衰
- **環境重力/環境風:** 方向一定加速度 + 突風/揺れ乱流
- **カーソル吸引+反発:** カーソル周辺の力場

## 音楽連動フレームワーク

WASAPI ループバックキャプチャ + Cooley-Tukey FFT + 3 種のビート検出 + マルチバンド解析 + BPM 推定 + 音楽物理連動（低音→重力、中音→磁場、高音→熱ノイズ）。

## インストール

1. [Windhawk](https://windhawk.net/) をインストール
2. `mouse-trail.wh.cpp` をダウンロード
3. Windhawk で「mod を作成」→ コードを貼り付け → 保存

## 関数トレイル変数

カスタム数式で使用可能：`t`（正規化 0=先頭 1=末尾）、`d`（先頭からのピクセル距離）、`time`（秒）。関数：sin cos exp sqrt abs。演算子：+ - * / ^。
